## The Formula

**Agent = Model + Harness.** Model capability alone is insufficient for production deployment — the surrounding infrastructure (tools, verification, context, guardrails, observability) determines reliability.

## Three Phases of AI Maturity (used to open the chapter intro)

1. Prompt engineering — 2022-23
2. Context engineering — 2024-25
3. Harness engineering — 2026

## Five Essential Harness Layers

1. Tool orchestration
2. Verification loops
3. Context and memory systems
4. Guardrails
5. Observability

## Supporting Data Point (secondary, not this chapter's case study)

The LangChain team "moved their coding agent from the 30th to the 5th place on Terminal Bench 2.0 without changing the underlying model at all" — cited here only as industry corroboration that harness changes can move rankings independent of the model. **Not used as this chapter's case study** (Anthropic is); included in source notes for completeness since it's the same formula in a different company's numbers.

## Critical Metrics the Post Recommends Tracking

Dollars per merged PR, time-to-merge, review velocity, compute spend per developer — cited as framing for how engineering leaders should evaluate harness investment, not as numbers reported by Anthropic's case study.
